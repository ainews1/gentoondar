**Enum PomodoroPhase:** `idle, ready, working, shortBreak, longBreak`

**Class PomodoroTimerState extends Equatable:**
```dart
class PomodoroTimerState extends Equatable {
  final PomodoroPhase phase;
  final bool isPaused;
  final DateTime? targetEndTime;  // Wall-clock when session ends
  final DateTime? pausedAt;       // When pause started
  final DateTime? sessionStartedAt; // When current session began (for saving)
  final int completedSessions;    // Work sessions in current cycle
  final int? linkedTaskId;
  final Duration totalPausedDuration; // Accumulated pause time for this session

  const PomodoroTimerState({
    this.phase = PomodoroPhase.idle,
    this.isPaused = false,
    this.targetEndTime,
    this.pausedAt,
    this.sessionStartedAt,
    this.completedSessions = 0,
    this.linkedTaskId,
    this.totalPausedDuration = Duration.zero,
  });

  Duration get remainingTime {
    if (targetEndTime == null) return Duration.zero;
    if (isPaused && pausedAt != null) {
      return targetEndTime!.difference(pausedAt!);
    }
    final remaining = targetEndTime!.difference(DateTime.now());
    return remaining.isNegative ? Duration.zero : remaining;
  }

  bool get isActive => phase == PomodoroPhase.working || phase == PomodoroPhase.shortBreak || phase == PomodoroPhase.longBreak;
  bool get isCompleted => isActive && !isPaused && remainingTime == Duration.zero;
}
```

**Class PomodoroTimerNotifier extends Notifier<PomodoroTimerState>:**
- NOT autoDispose (per Research pitfall 5 — timer must survive tab switches)
- `build()` returns `const PomodoroTimerState()` (idle)
- `selectTask(int taskId)` — sets linkedTaskId, phase = ready if idle
- `startWork()` — reads settings from `pomodoroSettingsProvider`, sets phase = working, targetEndTime = `DateTime.now().add(Duration(minutes: settings.workDurationMinutes))`, sessionStartedAt = now
- `pause()` — sets isPaused = true, pausedAt = DateTime.now() (per D-15: no time limit)
- `resume()` — calculates pauseDuration = now - pausedAt, adds to totalPausedDuration, adjusts targetEndTime += pauseDuration, clears pausedAt, isPaused = false
- `skipBreak()` — if in break phase, transition to work pending (per D-14)
- `stop()` — saves current session as partial (isCompleted = false) via completePomodoroSessionUseCaseProvider, resets to idle (per stop flow)
- `switchTask(int newTaskId)` — updates linkedTaskId (per D-10)
- `onTimerTick()` — called by UI timer, checks if remainingTime <= 0, if so calls `_onSessionComplete()`
- `_onSessionComplete()` — saves completed session, increments completedSessions if work, determines next phase:
  - After work: if completedSessions % longBreakInterval == 0 -> longBreak, else shortBreak
  - After break: next work
  - Checks autoStartBreaks / autoStartWork settings (per D-06)
  - Triggers SnackBar message via a separate `pomodoroMessageProvider` (StateProvider<String?> that UI watches)
- `onTaskCompleted(int taskId)` — if linkedTaskId == taskId, stop timer and save partial (per D-11)
- `reset()` — returns to idle state, clears everything

**Provider declarations:**


The wall-clock approach ensures background resilience per D-12: when app resumes, `remainingTime` getter automatically recalculates from `targetEndTime` vs current time. Per D-13, since state is in memory only (not persisted), cold restart resets everything.
