- `class PomodoroFab extends ConsumerStatefulWidget`
- Wraps a child widget in a `Stack`, positioning the FAB at bottom-right (16px from edges)

- Tap toggles `_showPanel` state, animates TimerPanel in/out
- TimerPanel slides up from bottom (300ms easeOut) / down (200ms easeIn)
- Positioned above the bottom nav bar (use `MediaQuery.of(context).padding.bottom + kBottomNavigationBarHeight`)
- `Semantics(label: 'Pomodoro Timer. ${isActive ? "Running" : "Stopped"}')`
- FAB tooltip: "Pomodoro Timer"
- Also listen to `pomodoroMessageProvider` — when non-null, show SnackBar with the message text (floating behavior, 4 seconds, bodyMedium 14px) and reset provider to null

**lib/presentation/widgets/pomodoro/timer_countdown.dart** (per UI-SPEC):
- `class TimerCountdown extends ConsumerWidget`
- Outer diameter: 100px, ring stroke: 8px
- Uses `CustomPainter` to draw:
  - Background ring: theme secondary at 20% opacity
  - Fill ring: state color (work=`#E53935`, shortBreak=`#43A047`, longBreak=`#1E88E5`, paused=`#9E9E9E`)
  - Ring animates counterclockwise (sweep angle = remaining / total * 2*pi)
- Center: countdown text in Display typography (48px), monospaced via `fontFeatures: [FontFeature.tabularFigures()]` — format "MM:SS"
- Below digits: session type label "Work" / "Short Break" / "Long Break" in Label (14px)
- Uses `Timer.periodic(Duration(seconds: 1), ...)` to trigger UI rebuild and call `timerNotifier.onTimerTick()`
- Semantics: update every 30 seconds with "{MM} minutes {SS} seconds remaining"

**lib/presentation/widgets/pomodoro/timer_controls.dart** (per UI-SPEC):
- `class TimerControls extends ConsumerWidget`
- Horizontal row of 3 IconButtons with filled tonal variant, 48px touch targets:
  - Pause/Resume toggle: `Icons.pause` / `Icons.play_arrow` — calls `timerNotifier.pause()` / `.resume()`, tooltip "Pause"/"Resume"
  - Skip: `Icons.skip_next` — calls `timerNotifier.skipBreak()` (only enabled during breaks per D-14), tooltip "Skip to next session"
  - Stop: `Icons.stop` in destructive color `#F44336` — shows AlertDialog confirmation:
    - Title: (none)
    - Content: "Stop this session? Progress will be saved as a partial session."
    - Actions: TextButton "Keep Going" (left), ElevatedButton "Stop Session" in red (right)
    - On confirm: calls `timerNotifier.stop()`
- When timer is in idle/ready: show single play button to start, calls `timerNotifier.startWork()`
