class PomodoroTheme {
  final String id;

}

Providers:

- `themeUnlockCheckProvider` — Provider that checks if a new theme was just unlocked (compare previous count to current), if so sets `pomodoroMessageProvider` with unlock message per UI-SPEC (e.g., "Cyberpunk theme unlocked! 25 sessions of pure focus.")

**lib/presentation/providers/pomodoro_audio_providers.dart:**

Create `PomodoroAudioService` class:
```dart
class PomodoroAudioService {
  final AudioPlayer _effectPlayer = AudioPlayer();
  double _volume = 0.7;
  String _currentThemePrefix = 'neon';
  bool _isMuted = false;

  Future<void> playWorkComplete() async { ... }
  Future<void> playBreakComplete() async { ... }
  Future<void> playTimerStart() async { ... }
  Future<void> playSkip() async { ... }
  Future<void> playStop() async { ... }
  Future<void> playUnlock() async { ... }
  Future<void> playPenguinChirp() async { ... }

  void setVolume(double volume) {
    _volume = volume;
    _isMuted = volume <= 0;
  }
  void setTheme(String themePrefix) => _currentThemePrefix = themePrefix;
  void dispose() => _effectPlayer.dispose();
}
```

Each play method:
1. Check `_isMuted` — return early if true (per D-39: silent during work except completion sounds)
2. Set volume on player
3. Play from `AssetSource('sounds/$_currentThemePrefix/{event}.ogg')`
4. If asset not found (placeholder phase), catch error silently

Sound differentiation (D-42, Claude's discretion): work_complete uses a rising synth chord (attention-grabbing), break_complete uses a softer pad sound. Different asset files.

Provider:
- `pomodoroAudioServiceProvider` — Provider that creates PomodoroAudioService, reads volume and themeId from settings, disposes on ref.onDispose
