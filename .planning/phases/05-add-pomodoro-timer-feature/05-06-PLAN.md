**lib/presentation/widgets/pomodoro/penguin_renderer.dart** (per D-43, D-44, D-45):
- `class PenguinRenderer extends CustomPainter`
- Constructor: `PenguinRenderer({required this.state, required this.animationFrame, this.auraColor})`
- 16x16 logical pixel grid rendered into display size (80x80px area)
- `pixelSize = size.width / 16`

**Procedural generation using `Random(state.seed)`:**

Base penguin body (always drawn):
- Body: oval-ish shape, rows 4-13, cols 4-11 (dark color)
- Belly: lighter patch, rows 6-12, cols 6-9 (white/cream)
- Head: rows 2-5, cols 5-10
- Eyes: row 3, cols 6 and 9 (white with black pupil)
- Beak: row 4, cols 7-8 (orange)
- Feet: row 14, cols 5-6 and 9-10 (orange)

**Random variations (from seed, per D-45):**

Color palette (4 colors via `random.nextInt`):
- bodyColor: varies from black through dark blue, dark green, dark purple (8 options)
- bellyColor: white, cream, light blue, light yellow (4 options)
- beakColor: orange, yellow, red (3 options)
- feetColor: matches beak

Accessories (based on evolutionStage, 0-2 items):
- Stage 1+: option for hat (top of head, row 1, various styles — tiny top hat, beanie, crown)
- Stage 3+: option for scarf (row 5-6 overlap, colored)
- Stage 5+: option for glasses (row 3, over eyes)
- Accessory selection: `random.nextInt(accessoryPool.length)` from pool available at current stage

Size proportions (per D-45):
- bodyHeadRatio: `0.6 + random.nextDouble() * 0.2` (varies 0.6-0.8)
- Apply by adjusting head row range

Background aura (if auraColor provided):
- Draw soft glow behind penguin using auraColor at 20% opacity, 2px wider than body on each side
- Aura intensity increases with evolution stage

**Animation frames:**
The `animationFrame` int cycles through sprite variations:
- Frame 0: neutral
- Frame 1: slight left lean (shift body pixels 1 left)
- Frame 2: neutral
- Frame 3: slight right lean (shift body pixels 1 right)
- Frame 4-5: blink (eyes shrink to 1px height)
- Frame 6-7: look around (pupils shift position)

**Performance (per Research pitfall 4):**
- Cache `Paint` objects as class fields, not per-frame
- `shouldRepaint` compares `state != oldState || animationFrame != oldFrame`
- Don't allocate in `paint()`

**lib/presentation/providers/penguin_providers.dart:**
- `penguinStateProvider` — AsyncNotifierProvider<PenguinStateNotifier, PenguinState>
- `PenguinStateNotifier` with:
  - `build()`: loads from `PomodoroSettingsDatasource`, calculates seed from total sessions hash
  - `refreshFromSessions()`: queries total session count, recalculates evolutionStage and seed, saves
  - `updateStreak()`: calculates streak from session dates, updates state
  - `checkEvolution()`: compares before/after evolution stage, returns true if changed (for sparkle animation trigger)
- `penguinAnimationFrameProvider` — StateProvider<int> for current animation frame (managed by PenguinWidget's AnimationController)
