**Audio wiring in timer_panel.dart or pomodoro_fab.dart:**
Use `ref.listen` on `pomodoroTimerProvider` to detect state transitions:
- When phase changes from working to shortBreak/longBreak: call `audioService.playWorkComplete()`
- When phase changes from shortBreak/longBreak to working: call `audioService.playBreakComplete()`
- When timer starts (idle/ready -> working): call `audioService.playTimerStart()`
- When skip action: call `audioService.playSkip()`
- When stop action: call `audioService.playStop()`
- When theme unlocked (from themeUnlockCheckProvider): call `audioService.playUnlock()`

Per D-39: NO sounds play during active work sessions (no ticking).
Per D-40: Sound only, no haptics/vibration.

**Task completion auto-stop (D-11):**
In PomodoroFab or TimerPanel, add `ref.listen` on `taskListProvider`:
- When a task in the list changes from `isCompleted: false` to `isCompleted: true`
- Check if that task.id matches the timer's `linkedTaskId`
- If so: call `timerNotifier.onTaskCompleted(task.id)` which stops timer and saves partial

**Theme animations (D-32):**
Add basic per-theme animations to timer_panel.dart:
- Each theme has a subtle background animation based on its aesthetic:
  - Neon: pulsing glow on timer ring (opacity oscillates 0.5-1.0, 2 second period)
  - Space: slow star twinkle effect (3-4 small dots at random positions, opacity fade in/out)
  - Magic: gentle particle float upward (2-3 particles, slow drift)
  - Gentoo: terminal cursor blink near penguin (blinking underscore)
  - Cyberpunk: scanline sweep (thin horizontal line moves down panel, subtle)
  - Retro: CRT flicker (very subtle opacity variation, 100ms)
  - Zen: breathing glow (slow sine wave opacity on background, 4 second period)
- Implement using `AnimatedBuilder` + `AnimationController` with appropriate curves
- Keep animations minimal to maintain 60fps (per CLAUDE.md performance requirements)
- Only animate when timer is active, stop when idle

**No lock screen / persistent notification (D-18):**
Verify that NO code triggers platform notification channels or wake locks. The timer is app-internal only. This is already the case since we're using wall-clock timing without native timer services.

**Final integration check:**
- Ensure penguin state refreshes after session completion (call `penguinStateNotifier.refreshFromSessions()`)
- Ensure daily count/focus minutes providers invalidate after session save
- Ensure streak provider refreshes after session save
- Ensure analytics providers pick up new session data
