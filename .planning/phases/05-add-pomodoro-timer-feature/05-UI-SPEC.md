# Phase 5 — UI Design Contract

> Visual and interaction contract for the Pomodoro timer feature. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Flutter / Material 3) |
| Preset | not applicable |
| Component library | Material 3 widgets (Flutter built-in) |
| Icon library | Material Icons (Icons class) |
| Font | System default (Roboto on Android, SF Pro on iOS) |

**Note:** This phase extends the existing Material 3 theme defined in `lib/presentation/theme/app_theme.dart`. Timer-specific themes (D-31) are scoped to the timer panel only and do NOT override the app theme.

---

## Spacing Scale

Declared values (must be multiples of 4) — inherited from existing app patterns:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge internal padding |
| sm | 8px | Compact element spacing, timer control gaps |
| md | 16px | Default element spacing, panel padding |
| lg | 24px | Section padding, settings group spacing |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Timer display area vertical padding |
| 3xl | 64px | Page-level spacing (settings screen top) |

Exceptions:
- FAB size: 56px (Material 3 standard FAB)
- Timer panel height: 180px collapsed, expandable to 280px with penguin visible
- Touch targets: minimum 48px for all timer controls (exceeds 44px WCAG requirement)
- Penguin display area: 80x80px within timer panel

## Typography

Inherited from `AppTheme` — these roles apply to new Pomodoro-specific elements:

| Role | Size | Weight | Line Height | Phase 5 Usage |
|------|------|--------|-------------|---------------|
| Display | 48px | 600 (semibold) | 1.1 | Timer countdown digits |
| Heading | 20px | 600 (semibold) | 1.2 | Settings section titles, analytics chart titles |
| Body | 16px | 400 (regular) | 1.5 | Session type label, settings descriptions, SnackBar messages |
| Label | 14px | 500 (medium) | 1.4 | Timer panel metadata ("Today: 3 sessions"), preset names |
| Caption | 12px | 400 (regular) | 1.5 | Pomodoro badge count on task cards, unlock requirements |

**Timer countdown digits:** Use monospaced rendering (tabular figures) to prevent layout shift during countdown. Apply via `fontFeatures: [FontFeature.tabularFigures()]`.

## Layout Specifications

### FAB (PomodoroFab)

- Position: bottom-right, 16px from edges (Material 3 standard)
- Size: 56px diameter
- Icon: `Icons.timer` (24px), static at all times (D-03)
- Badge: when timer is running, show small circular indicator (12px) at top-right of FAB in work/break state color
- Z-index: above all content, below modal dialogs
- Tap action: toggle TimerPanel visibility

### Timer Panel (TimerPanel)

- Position: fixed at bottom of screen, above bottom nav bar
- Width: full screen width
- Height: 180px (compact) / 280px (with penguin expanded)
- Background: theme-specific secondary color with 95% opacity
- Border radius: 16px top-left, 16px top-right, 0 bottom
- Elevation: 8
- Entry animation: slide up from bottom, 300ms ease-out
- Exit animation: slide down, 200ms ease-in

**Compact layout (180px):**
```
[Task selector dropdown                    ] [X close]
[       Timer Ring (100px)  ]  Session: Work
[       MM:SS              ]  3/4 sessions
[  Pause  ] [  Skip  ] [  Stop  ]
Today: 5 sessions | 2h 05m focused   Goal: 5/8 [====    ]
```

**Expanded layout (280px):**
```
[Task selector dropdown                    ] [X close]
[  Penguin (80x80)  ] [  Timer Ring (100px)  ]  Session: Work
[                   ] [       MM:SS         ]  3/4 sessions
[  Pause  ] [  Skip  ] [  Stop  ]
Today: 5 sessions | 2h 05m focused   Goal: 5/8 [====    ]
Streak: 7 days
```

### Timer Countdown Ring

- Outer diameter: 100px
- Ring stroke width: 8px
- Ring background: theme secondary at 20% opacity
- Ring fill: work/break state color, animates counterclockwise
- Center: countdown digits in Display typography (48px, monospaced)
- Below digits: session type label in Label typography (14px)

### Timer Controls

- Layout: horizontal row, evenly spaced
- Button style: `IconButton` with filled tonal variant
- Button size: 48px touch target
- Icons: `Icons.pause` / `Icons.play_arrow` (toggle), `Icons.skip_next`, `Icons.stop`
- Stop button: destructive color (`#F44336`), requires confirmation tap (double-tap or hold 500ms)

### Task Selector Dropdown

- Width: full panel width minus close button (48px) minus padding (32px)
- Style: `DropdownButtonFormField` matching existing input decoration theme
- Items: today's incomplete tasks, showing task title + time
- Empty state: "No tasks for today" in bodyMedium, grey

### Penguin Widget

- Size: 80x80px display area
- Style: pixel art rendered via `CustomPainter`
- Idle animations: 4 loops (waddle, blink, look-around, dance), random interval 3-8 seconds
- Animation duration: 500-1000ms per cycle
- Procedural generation: color palette (4 colors), accessories (hat/scarf/glasses, 0-2 items), size proportions (body/head ratio varies 0.6-0.8), background aura (glow color from theme)

### Pomodoro Badge (on Task Card)

- Position: right side of task card, vertically centered
- Style: small circular badge, 24px diameter
- Background: `#E53935` (work red) at 15% opacity
- Text: session count in Caption typography (12px), bold
- Icon: `Icons.timer` at 10px, left of count
- Show only when count > 0

### "Start Pomodoro" Button (on Expanded Task Card)

- Position: in expanded task card action row, alongside Edit/Delete
- Style: `OutlinedButton` with timer icon
- Label: "Start Pomodoro"
- Icon: `Icons.timer` at 18px
- Only visible in expanded card view (D-17)

### Calendar Pomodoro Markers (D-27)

- Approach: small colored dots below task duration blocks
- Size: 6px diameter circles
- Color: `#E53935` at 60% opacity
- Max visible: 4 dots per task block (overflow shows "+N" in 10px text)
- Position: 2px below the task duration block bottom edge
- Spacing: 2px gap between dots

### Theme Picker Grid

- Layout: 2-column grid with 8px gap
- Card size: fill available width, aspect ratio 3:2
- Card content: theme name (Label, 14px), mini preview of color palette (3 swatches, 16px circles), lock icon overlay for earned themes
- Lock overlay: `Icons.lock` at 32px, centered, white with 60% opacity background
- Below lock: unlock requirement text in Caption (12px), e.g. "Complete 25 sessions"
- Selected card: 2px border in theme primary color

### Preset Selector

- Style: `SegmentedButton` (Material 3)
- Options: "Classic", "Deep Work", "Sprint", "Custom"
- When "Custom" selected: reveal `DurationSliders` below with 300ms slide animation

### Duration Sliders

- 3 sliders: Work (5-90 min), Short Break (1-30 min), Long Break (5-60 min)
- Style: Material 3 `Slider` with value label
- Label format: "{N} min" displayed in Label typography
- Step: 5 minutes for work, 1 minute for breaks

### Pomodoro Analytics Section

- Position: below existing productivity charts in Analytics tab
- Section title: "Focus Sessions" in Heading typography (20px)
- Chart 1: "Daily Focus Sessions" — bar chart, x-axis days, y-axis session count, bars in `#E53935`
- Chart 2: "Focus by Task" — horizontal bar chart, task name on y-axis, session count on x-axis, bars in `#1976D2`
- Chart style: follow existing `fl_chart` patterns from `task_count_chart.dart` and `busy_minutes_chart.dart`
- Range selector: reuse existing `analyticsRangeProvider` for weekly/monthly toggle

### Settings Screen Layout (D-53)

Single scrollable page, sections separated by 24px spacing:

```

  [SegmentedButton: Classic | Deep Work | Sprint | Custom]
  [Duration Sliders (if Custom)]

  [Slider: Target sessions per day (1-20, default 8)]

  [Slider: Pomodoro volume (0-100%)]

  [TextField: Penguin name]
  [Preview: Current penguin appearance (80x80)]

```

### SnackBar Messages (D-29, D-30)

- Position: bottom of screen, above timer panel if visible
- Duration: 4 seconds
- Style: Material 3 SnackBar with `SnackBarBehavior.floating`
- Max lines: 2
- Typography: bodyMedium (14px)

## Interaction Contracts

### FAB Tap

1. If timer panel is hidden: slide panel up (300ms ease-out)
2. If timer panel is visible: slide panel down (200ms ease-in)
3. If no task is selected: panel opens with task selector focused

### Start Pomodoro (from Task Card)

1. Set linked task to tapped task
2. Open timer panel (if not open)
3. Pre-select the task in dropdown
4. Begin work session countdown (if auto-start enabled) or show "Tap play to start"

### Timer State Transitions

```
IDLE → [select task] → READY → [play] → WORK_ACTIVE
WORK_ACTIVE → [pause] → WORK_PAUSED → [resume] → WORK_ACTIVE
WORK_ACTIVE → [complete] → BREAK_PENDING → [auto/manual start] → BREAK_ACTIVE
WORK_ACTIVE → [skip] → BREAK_PENDING
BREAK_ACTIVE → [complete] → WORK_PENDING → [auto/manual start] → WORK_ACTIVE
BREAK_ACTIVE → [skip] → WORK_PENDING
ANY_ACTIVE → [stop] → confirm dialog → IDLE (save partial)
ANY_ACTIVE → [task completed externally] → IDLE (save partial, D-11)
ANY → [close panel] → panel hidden (timer continues in background if active)
```

### Stop Confirmation

1. User taps Stop button
2. Show `AlertDialog` with destructive confirmation copy
3. "Keep Going" (TextButton, left) / "Stop Session" (ElevatedButton, destructive red, right)
4. On confirm: save partial session, reset to IDLE, show SnackBar "Session stopped. Partial progress saved."

### Theme Selection

1. User taps theme card in settings
2. If unlocked: apply theme immediately, show brief preview animation (200ms)
3. If locked: show tooltip with unlock requirement, no state change

### Penguin Evolution

1. After every completed work session: check if evolution threshold crossed
2. If new evolution: play subtle sparkle animation (500ms) in timer panel
3. Sparkle: 8-12 small particle dots radiating outward from penguin, theme glow color, fade out

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Timer countdown | `Semantics(label: "{MM} minutes {SS} seconds remaining")`, update every 30 seconds (not every second) |

## Sound Design Contract
